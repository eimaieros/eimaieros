### What I publish here

**[framebudget](https://github.com/eimaieros/framebudget)** — a runtime frame budget for animated websites. It measures real frame timing in production and turns the animation down before the user feels the stutter. Percentile-based rather than mean-based, because nobody perceives an average. 58 tests, 11.7 KB minified, zero dependencies.

**[glaze](https://github.com/eimaieros/glaze)** — GPU effects over the DOM you already have. WebGPU, scroll-driven, and it never removes your content: the texture is uploaded before the element is hidden, and every failure path leaves the original page untouched. 91 tests, 17.2 KB minified, zero dependencies.

**[cadence](https://github.com/eimaieros/cadence)** — a technical interview simulator. FastAPI, PostgreSQL 16 and Next.js, with answers streamed token by token over SSE. 120 tests; the 96 backend ones run against a real PostgreSQL, because the schema uses JSONB and native enums and a SQLite suite would pass while production broke.

**[portfolio](https://github.com/eimaieros/portfolio)** — the source of [rodrigofigueiredo.dev](https://rodrigofigueiredo.dev). One HTML file, no framework, WebGL background on Three.js. A verification pipeline runs the page in jsdom with and without WebGL, audits accessibility and SEO, and blocks the build on regression.

**Tamagotchi** and **Personal-Finance-Tracking-App** are from February 2025 and stay up on purpose. The August 2026 commits on both are the interesting part: what I would do differently, done rather than described.
